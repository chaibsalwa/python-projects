# 📝 To-Do List App - Python

A simple and clean To-Do List application built with Python.

## Features
- ✅ Add new tasks
- 📋 List all tasks
- ✔️ Mark tasks as complete
- 🗑️ Delete tasks

## Tech Stack
- Python 3
- No external dependencies

## How to Run

python todo.py
